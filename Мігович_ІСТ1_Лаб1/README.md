## 🛠 Перелік застосованих технік та технологій
1. **Семантична розмітка (HTML5):** Використання тегів `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`.
2. **CSS Flexbox:** Застосовано для вирівнювання елементів у шапці (header), головному екрані (hero), карток та додаткової секції акцій.
3. **CSS Grid:** Застосовано для створення складних сіток каталогу товарів та блоків переваг.
4. **Адаптивність та мобільний підхід (Mobile First):** Реалізовано через медіазапити (`@media`), гнучкі контейнери без горизонтального скролу на ширині від 360px.
5. **Адаптивна типографіка:** Використання відносних одиниць (`rem`) та функції `clamp()` для плавного масштабування заголовків.
6. **CSS-змінні:** Усі основні кольори (зокрема акцентний `--color-accent: #3A7CA5`) винесені у глобальні змінні `:root`.
7. **Додаткова секція:** Додано секцію спеціальних акційних пропозицій (`.promo-section`) відповідно до вимог індивідуального завдання.

---

## 📱 Скріншоти та контроль ширини
* **Десктопна версія (1920px):** контент центрується, фонові елементи розтягуються на всю ширину.
* **Мобільна версія (360px):** повна відсутність горизонтального скролу, елементи адаптовані під вертикальний екран.
